How to Report a Potential Vulnerability
=======================================

If you think you have found a security vulnerability in meta-e3, report it
privately through a GitHub security advisory at
https://github.com/epics-e3/meta-e3/security/advisories/new, or by email to
the maintainer listed in README. Do not open a public issue or pull request.

Vulnerabilities in the software packaged by this layer (EPICS base, pvxs,
require, iocStats, ...) should also be reported to the respective upstream
project.

Vulnerabilities in OpenEmbedded-Core or BitBake should be reported to the
Yocto Project as described in
https://docs.yoctoproject.org/contributor-guide/report-security-vulnerability.html
